# 代码格式规范

适用于 Java 源码和测试，手写、AI 编写与 IDEA 生成使用同一标准；自动排版以 [`.editorconfig`](../../.editorconfig) 为准。

## 排版

- UTF-8、LF；缩进 4 空格，续行 8 空格，不用 Tab；去除行尾空白，文件末尾保留换行。
- 行宽目标 120 列：参数在逗号后换行，条件在运算符前换行，调用链在 `.` 前换行。不为行宽改变字符串或文本块内容。
- 左花括号同行，`else`、`catch`、`finally` 紧跟右花括号；条件和循环体使用花括号，非空代码块不压成单行。
- 控制关键字与 `(` 之间空一格，方法名与 `(` 之间无空格；逗号后、二元运算符及 `->` 两侧空一格，`::` 两侧无空格。
- 每行一条语句，声明注解各占一行；方法间空一行，逻辑段按需空一行，不堆叠空行。
- 新增导入不用 `*`。依次分组为项目／第三方、`javax`／`java`、静态导入，组间空一行，组内由 IDEA 排序。

## 注释

- 中文、简洁、符合实现；说明职责、约束和原因，不复述显然的代码。修改逻辑时同步注释，保留必要的兼容说明和 TODO。
- 声明文档使用 `/** ... */`，每行以 ` *` 开头，结束符独占一行；方法内部说明使用 `//`。简单访问器和纯委托方法无需重复文档。
- 正文与标签区空一行，标签间不空行；顺序为 `@param`、`@return`、`@throws`。参数按声明顺序，类型参数在前，名称与签名一致。
- 标签须有实际说明；必要的空值、默认值、单位、副作用和异常条件写清。构造方法和 `void` 方法不写 `@return`。
- 删除空标签、过期或冗余注释；不新增作者、日期模板及 `@date`、`@CreateTime`、`@description` 等非标准标签。
- 类型、表达式和示例用 `{@code ...}`，引用用 `{@link ...}`；泛型、比较符等不能裸写成 HTML，段落和列表保持合法 HTML。

## 使用

- IDEA 开启 EditorConfig，生成注释后补齐说明，再执行 Reformat Code；导入用 Optimize Imports。个人模板不添加作者、日期头；其他 AI 工具需显式提供本规范。
- 只整理本次修改范围，不顺带整库重排。检查差异和 `git diff --check`，确保逻辑及字符串内容不变；导入调整按影响范围编译验证。
