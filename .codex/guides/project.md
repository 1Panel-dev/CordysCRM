# 团队约定

默认中文沟通。实现和命令以当前代码、POM/package.json 与工具配置为准。

- 沿用现有风格，优先复用已有能力，完成任务范围内的工作；注释解释非直观意图，避免无关重构。
- 尊重已有修改，保留校验、权限与数据范围、事务、错误处理和基本可访问性；不泄露敏感信息或绕过审批。
- 任务内自主推进，已有授权持续有效；提交、推送、合并、发布、部署和对外发消息须有明确授权。
- 依赖、锁文件和生成文件通过对应工具更新。需要时并行分工，避免写入冲突；审查默认只读。
- 提交遵循 Conventional Commits，主题为单行英文；用户提供正文时隔一个空行并原样保留，无正文不附加空行。
- 按实际影响选择足够的验证，交付简要说明结果与未验证事项；[常用命令](../verification.md)仅供按需查阅。
- 个人偏好和环境约定保存在本地，不提交仓库；团队约定写入 `.codex/`。更新 Agent 记忆不修改 `README*`、`REDEME*` 等项目说明。
